# Emmanuel Ogbinaka — portfolio preview

Unzip and open dist/index.html in a modern browser. The portfolio is split across Home, Work, About, Writing and Contact pages. No server, install or build is required.

The project details and image credits are in dist/app.js. The complete project gallery and open-source projects are on dist/work.html; the experience row appears on the home page before Selected Work. The theme is light by default and remembers an explicit dark-mode choice on browsers that allow local storage. Project detail dialogs close with Escape or Close.

The public previews depict the publicly accessible product material, not necessarily the historical version Emmanuel worked on. Vendor Management is an internal project and uses a labeled workflow illustration. Jumia’s end date is not asserted; the experience section lists its confirmed start month. Contact directs to Emmanuel’s LinkedIn profile; DEV.to remains linked for writing and profile discovery.
